使用条款

Eat 用于减少“今天吃什么”的选择成本。推荐结果是随机候选，不构成营业、价格、过敏原、食品安全或其他保证。

预算、代表菜、营业信息和距离可能不完整或发生变化。出发前请通过店铺官方信息或你选择的地图服务再次确认。

现有记录中的 Google Place ID 仅作为历史兼容身份和普通外部导航链接的一部分保留；当前数据维护不通过付费 Google Places API 刷新或扩展这些身份。

部分基础地点信息来自 OpenStreetMap；OpenStreetMap 数据由 OpenStreetMap contributors 提供并适用 Open Database License (ODbL)。新的批量候选研究也可能使用 Overture Maps 的公开数据，进入生产前仍需独立审查并遵守相应来源许可与署名要求。
