隐私说明

Eat 是一个静态餐厅随机选择页面。当前版本不要求登录，也不会主动收集姓名、邮箱、精确位置或设备指纹。

当前版本没有服务器端用户数据库，也不会由本页面保存你的筛选条件或推荐历史。

当前页面的内嵌地图使用 OpenStreetMap/Leaflet，不向页面注入 Google Maps API key，餐厅数据维护也不执行付费 Google Places 数据请求。

点击“在 Google Maps 查看”等普通外部导航链接后，你会离开本页面并进入第三方网站；该服务的数据处理适用其自身隐私政策。

GitHub Pages 作为静态托管平台可能按照其自身政策处理必要的访问日志和网络信息。
